# Midnight Gambit

**Midnight Gambit** is a custom tabletop role-playing game system built for [Foundry Virtual Tabletop](https://foundryvtt.com/).

Built around cinematic storytelling, player creativity, and risk-versus-reward mechanics, Midnight Gambit provides a flexible framework for adventures across a variety of settings.

## Features

- **Custom Dice System**: A dice-pool system with varying degrees of success and failure.
- **Guise System**: Create unique characters by combining character archetypes and abilities.
- **Gambits**: A card-inspired ability system that gives players tactical options.
- **Spark**: A flexible magic system built around creative spellcasting.
- **Custom Character Sheets**: Integrated character management, inventory, and abilities.
- **GM Tools**: Features to help manage encounters, NPCs, and group checks.

## Installation

Midnight Gambit is designed for use with Foundry Virtual Tabletop.
